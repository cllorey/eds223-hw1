# EDS 223 Homework 1: Map-making and Environmental Justice

## Purpose
This repository contains data and code to explore and visualize environmental justice issues in the United States. In particular, this project utilizes the US Environmental Protection Agency EJScreen data from 2023 to look at the demographic index and air quality in Loudoun County, Virginia.

## Repository Structure 
This repository is structured as follows:

```
├── data
│   └── ejscreen
├── ej_screen.pdf
├── ej_screen.qmd
└── README.md
```

## Data Access
The data used in this project originated from the United States Environmental Protection Agency’s previous EJScreen: Environmental Justice Screening and Mapping Tool. As the EPA EJScreen tool and official website is no longer available, data was accessed from a Google Drive folder provided on the [EDS 223 Course Website](https://eds-223-geospatial.github.io/assignments/HW1.html). It can be downloaded using [this link.](https://drive.google.com/file/d/1nG6Nj1bXfzQFOVMO8Km3eNy4SWu1YcIQ/view?usp=sharing)
